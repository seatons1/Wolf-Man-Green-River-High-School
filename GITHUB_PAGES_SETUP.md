# Publish Wolf-Man on GitHub Pages

1. Create a new **public** GitHub repository named `Wolf-Man-Green-River-High-School`.
2. Upload the contents of this folder to the repository root.
3. Commit the files to the `main` branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment → Source**, select **GitHub Actions**.
6. Open the **Actions** tab and wait for **Build and Deploy Wolf-Man** to finish.
7. GitHub will show the live Pages URL in the workflow's deployment environment.

Every later push to `main` will rebuild and redeploy the browser game.

Do not upload passwords, access tokens, or other private credentials to the
repository.
